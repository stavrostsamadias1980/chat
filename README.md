## ⚡ Γρήγορη Εκκίνηση (Quick Start)

Εκτελέστε από το root directory:
```powershell
python start_system.py
```
*(ή κάντε διπλό κλικ στο `start_system.bat`)*

### 🌐 Υπηρεσίες & Endpoints:
* **Angular 22 Standalone Widget:** [http://localhost:4200/](http://localhost:4200/)
* **Spring Boot 3 Real-time WebSocket (Exclusive Protocol):** `ws://localhost:8088/ws/chat`
