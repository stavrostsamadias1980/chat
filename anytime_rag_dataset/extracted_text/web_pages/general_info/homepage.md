# Καλωσήρθατε στην υπηρεσίαmy anytime!


Μέσω της υπηρεσίας my anytime μπορείτε να παρακολουθείτε και να διαχειρίζεστε online τα συμβόλαιά σας, έχοντας 24 ώρες το 24ωρο τη δυνατότητα να:

- βλέπετε αναλυτικές πληροφορίες για τα συμβόλαιά σας (π.χ. καλύψεις συμβολαίου, ημερομηνία ανανέωσης κ.λπ.).

- να έχετε πρόσβαση σε όλα τα απαραίτητα έγγραφα (π.χ. ασφαλιστήριο, πράσινη κάρτα).

- παρακολουθείτε την πορεία των φακέλων σας για ζημιές αυτοκινήτου και να ανεβάζετε σχετικά έγγραφα.

- πληρώνετε τα ασφάλιστρά σας, χωρίς καμία επιβάρυνση και να παρακολουθείτε τις πληρωμές σας.

- πραγματοποιείτε αλλαγή στα στοιχεία της κάρτας από την οποία πληρώνεται αυτόματα το συμβόλαιό σας.

- αλλάζετε τα στοιχεία επικοινωνίας σας (e-mail, κινητό τηλέφωνο).

- βρίσκετε απαντήσεις στα πιο συχνά σας ερωτήματα.

- επικοινωνείτε μαζί μας για θέματα που αφορούν τα συμβόλαιά σας.

- επωφελείστε από τις προσφορές και τις εκπτώσεις του Anytime Club!
